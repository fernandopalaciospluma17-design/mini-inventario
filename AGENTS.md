# Instrucciones del proyecto

- Mini Inventario es una aplicación web de inventario.
- El proyecto usa Node.js 22 y Python 3.12.
- Realiza cada cambio en una rama propia y envíalo mediante un pull request.
- Nunca subas llaves, secretos ni archivos `.env` al repositorio.
- Pide aprobación antes de borrar datos o desplegar.
