# Mini Inventario

Aplicación web de inventario. Requiere Node.js 22 y Python 3.12.

## Cómo empezar

Clona el proyecto y entra en la carpeta:

```bash
git clone https://github.com/fernandopalaciospluma17-design/mini-inventario.git
cd mini-inventario
```

Comprueba las versiones instaladas:

```bash
node --version
python --version
```

Se requiere Node.js 22 y Python 3.12.
