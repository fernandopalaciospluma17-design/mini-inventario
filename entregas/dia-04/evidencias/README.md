# Evidencias pendientes

Cuando se conecte el proyecto Supabase y se creen dos cuentas confirmadas, guarda aquí:

- `usuario-a.png`: sesión de A mostrando su producto de prueba.
- `usuario-b.png`: sesión de B mostrando su producto, sin el producto de A.
- Si es posible, capturas adicionales de A después de volver a iniciar sesión y de las pruebas negativas de RLS.

Las capturas deben ser reales. No incluyas contraseñas, tokens ni claves.
